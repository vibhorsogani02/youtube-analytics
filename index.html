Common questions

Where do I get an API key?

Open Google Cloud Console, create a project, enable “YouTube Data API v3”, then create an API key under Credentials.

Where do I find my channel ID?

In YouTube Studio go to Settings → Channel → Advanced settings. You can also type your @handle.

Why is the growth chart a model?

The Data API returns totals only. Day-by-day history requires the YouTube Analytics API, so the trend is generated to match your real totals.
